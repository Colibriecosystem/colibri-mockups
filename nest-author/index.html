Путь автора — вкладка «Автор» в окне Nest

Один кликабельный прототип всего пути автора виджета: стать автором, завести виджет, связать его с кодом, выпустить версию, поделиться, обновлять, следить и снять с публикации. Всё на одной вкладке терминала. Главное здесь — мастер выпуска: номер версии → «Что нового» → сборка → отправка, а дальше решение приходит в строку версии.

Как пользоваться

Внизу страницы прототипа — жёлтая полоса MOCKUP. Это пульт для ревью, а не часть интерфейса:

  • ширина — окно Nest на 800, 1024 или 1280 px; на 800 список виджетов и страница виджета открываются по очереди;
  • автор — ещё не автор, автор без виджетов, обычный автор, ID не читается, нет сети (отправка версии тогда падает);
  • объём — «первая поставка» прячет всё, что сделаем позже; «весь путь» показывает это с пометкой «позже»;
  • шаги пути — сразу на экран шага 1–8;
  • глазами пользователя — вкладка «Каталог»: как пользователь видит «Что нового» перед обновлением.

Каждый экран — свой адрес, его можно скопировать в замечание.

Что настоящее

Автор Colibri и два его виджета из публичного каталога — «Фандинг-монитор» и «Радар ликвидаций»: названия, описания, категории, теги, разрешения и адреса. Всё остальное нарисовано: другие виджеты, даты, числа, «Что нового», переписка, папки. Отказы и снятия есть только у выдуманных виджетов. У «Радара ликвидаций» намеренно нет статистики: нет данных — значит пусто, а не ноль. Состояние живёт в памяти: перезагрузка страницы начинает заново. Только русский.

Что проверить

  • Сводка: про каждый виджет понятно, в каком он состоянии и что с ним делать дальше.
  • «Что дальше» на странице виджета: одна фраза и одно главное действие в любом состоянии.
  • Мастер выпуска: предложенный номер, «Что нового» (обязательно для обновления), сборка с тем, что изменится для пользователей.
  • «В каталог / Только по ссылке» — на каждой отправке: у первой версии по умолчанию «В каталог», у обновления — как сейчас. В каталог — запрос модератору вместе с версией; из каталога — сразу после автоматических проверок.
  • После отправки проверки идут прямо в строке версии; ответ модератора и переписка — там же, а не в диалоге.
  • Отклонённая версия: причина, что исправить и «Отправить новую версию…» — это тот же мастер.
  • Отозвать версию с проверки и изменить «Что нового» без новой версии.
  • Связать папку: видно, какую строку widget.json терминал меняет.
  • Ссылку на виджет можно скопировать в любой момент, а не только сразу после отправки.
  • «Глазами пользователя»: «Что нового» перед обновлением и предупреждение о новом доступе.
  • Ширина 800: ничего не обрезано, есть путь назад к списку.
  • «Первая поставка»: без отмеченного «позже» путь остаётся цельным.
